# Future Feature Ideas

This file contains a list of potential features and improvements for the project. Feel free to contribute your own ideas!

- **User accounts:** Allow users to create accounts to save their download history and preferences.
- **More output formats:** Support for more output formats like MOBI and PDF.
- **Plugin system:** Allow other developers to create plugins to support more novel websites.
- **Improved UI/UX:** Continuously improve the user interface and experience to make the app more intuitive and user-friendly.
